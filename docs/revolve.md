## 圆环示例

创建圆形草图：半径 2，圆心 X=10、Y=0、Z=0。
点击旋转，选择该草图，旋转轴选世界 Y，角度 360°，生成圆环实体。
角度改成 180°得到半圈，修改原草图半径或位置会重算。
创建、参数修改和级联删除支持撤销重做，原生保存打开保留参数和草图依赖。

## 数据流

actionRevolve → on_actionRevolve_triggered → createRevolveFeature
→ 依赖图记录一个草图输入 → RevolveFeature::rebuild
→ revolveWire 填面 → BRepPrimAPI_MakeRevol → 检查实体有效性。

旋转保存angle（度）、axis（0=X、1=Y、2=Z）和结果平移XYZ（毫米，默认0），几何层转换为弧度。
UI 与文档角度范围为 0.001–360°，属性面板使用度数后缀和轴下拉框。
创建失败不增加特征、不破坏重做；之后编辑造成重建失败时显示状态并暴露上游草图。

旋转轴经过世界原点，支持X/Y/Z，生成独立实体；矩形、圆形、自定义轮廓及变换后的工作平面闭合线框均可作为截面。轴须平行草图平面，XZ轮廓绕Z可生成竖直杯身，详见 [扩展建模](advanced-modeling.md)。
不含任意轴、自动加料合并、旋转切除和对称旋转。轮廓应避免跨越旋转轴。

AI create_revolve参数为sketch_id、angle（度）和可选axis（X/Y/Z，默认Y）。
创建、查询和属性修改都返回实际重建结果；角度下限在文档、领域和几何层统一为 0.001°。
跨轴重建失败会明确指出对应世界轴及应调整的位置；修正上游或撤销后可恢复。

## 旋转结果定位

先按原草图绕世界原点X/Y/Z轴生成，再应用XYZ世界平移量。
平移不改变草图位置或旋转轴定义，之后编辑角度、轴或草图仍保留这份平移。
重复设置XYZ会替换已有平移量，不累计移动；XYZ的范围为±1000000毫米。
属性面板显示平移XYZ及说明；旋转结果没有点击定位，可使用create_transform进一步改变实体姿态。

AI 示例：圆形草图半径2、圆心(10,0,0)，绕Y旋转180或360度，
再用 `set_position` 对生成的Revolve ID设置(35,0,120)，半环/圆环的参考中心移到(35,0,120)。
中心圆平行XZ；绕X则平行YZ。若原始环心不为零，目标环心=原始环心+平移量。
设置结果Z与改变草图Z是不同操作；需用 `analyze_geometry` 核对方向、实际边界和布尔连接。

一次XYZ设置占一条撤销历史，下游布尔自动重建；平移后的结果也可参与拉伸切除与STEP导出。
新文档保存五个旋转参数。旧文件只有angle/axis时，读取补齐XYZ=0；
未知字段、非有限值和越界位置仍拒绝，失败读取保留当前文档。旧程序不具备新平移参数的读取能力。
测试覆盖X/Y轴整环与半环的尺寸/体积、非累积平移、一次撤销、依赖连接、旧文件兼容、
非法参数保护以及AI定位/属性编辑/历史/保存的UI流程；不包含真实模型服务的自然语言验收。
