# ForgeCAD 保命版路线图（2026.8.27 定稿）

> 你的情况：秋招就在下个月（2026 年 9-10 月），每天可投入 4h+，C++ 水平为"会写简单类、不懂内存管理"，算法底子好（数据结构 / DAG / 复杂度没问题）。
>
> 策略：**深度优先**。不做"功能多"的 CAD，做一个"核心够深、能撑住 30 分钟面试深挖"的 ForgeCAD。
>
> 大原则：**项目 = 课程**。学一点，马上写进 ForgeCAD，让它每周长大一截。

---

## 总目标（4 周）

- ✅ 一个能跑起来的 ForgeCAD（Qt 窗口 + OCCT 建模 + 自己写的参数化核心）
- ✅ 一个能讲 30 分钟的"深挖点"：参数化 Feature 系统 + Undo/Redo + 依赖图（全部亲手写的纯 C++）
- ✅ 现场改代码不慌：核心模块每一行都熟
- ✅ 面试八股覆盖 C++ 内存 / 并发 / 工程化核心问题

## 明确砍掉（秋招前不做）

- ❌ Sketch 约束求解器
- ❌ AI 建模助手
- ❌ 网络 / SQLite
- ❌ OpenGL 手写渲染（3D 视图走 OCCT AIS 或 Qt 简单方案）
- ⚠️ 完整 STEP 导入导出：能"讲"即可，来不及就只讲不写
- ⚠️ 性能基准：只做最小 benchmark 演示，不做全套 P95/P99

> 原文档自己也写了"不要为了技术栈而技术栈"。这些砍掉的功能，秋招上岸后随时能再加回来。

## 四周计划

### 第 1 周：C++ 核心补课 + 参数化地基（ForgeCAD v0.1）
- **主题**：内存管理（new/delete 为什么危险）、RAII、Rule of 0/3/5、智能指针、移动语义、const、异常安全
- **素材**：`docs/day1-modern-cpp-foundation.md`（已写好）
- **产出**：手写 Buffer、多态 Shape/Box、能编译运行、15 个面试题能答
- **项目产出**：`src/domain` 出现 Parameter / Feature 雏形 + 单测

### 第 2 周：Feature 系统 + Undo/Redo（ForgeCAD v0.2，核心之核心）
- **主题**：OOP/SOLID、设计模式（Factory / Command / Observer）、STL 实战
- **产出**：参数化 Feature（Box / Cylinder / Extrude）、Feature 树、依赖图（算法强项：DAG + 拓扑排序）、Command 栈 + Ctrl+Z/Y、GoogleTest 覆盖核心逻辑
- **面试点**：为什么用 Command、Undo/Redo 怎么实现、依赖图怎么重建

### 第 3 周：OCCT 几何 + Qt GUI（ForgeCAD v0.3，看得见的进步）
- **主题**：3D 数学（向量 / 矩阵 / 坐标变换）、B-Rep 概念（Geometry vs Topology）、OCCT 建基本体 / 布尔 / 分析
- **产出**：ShapeFactory 扩展（Cylinder / Sphere / Boolean）、几何分析（体积 / 包围盒）、Qt 主窗口 + 模型树 + 属性面板 + 3D 视图
- **面试点**：B-Rep、拓扑结构、布尔运算容差、为什么用 OCCT 不自研内核

### 第 4 周：并发 + 工程收尾 + 面试冲刺
- **主题**：多线程（mutex / condition_variable / atomic / 线程池）、任务系统
- **产出**：后台任务（加载 / 计算不卡 UI）、完整测试集、日志、README / 架构文档、benchmark 演示、Git 历史整理
- **面试冲刺**：项目问答稿（50 题）、简历项目描述、模拟面试

## 每天怎么过（4h）

1. **听课 / 读文档**（1h）：我讲，你提问，我用大白话解释
2. **手写练习**（1h）：不动笔不算学
3. **项目推进**（1.5h）：把今天学的写进 ForgeCAD
4. **面试题自答**（0.5h）：当天的题不看资料讲 2 分钟

## 教学循环

```
我讲 → 你动手 → 发代码给我批改 → 我反馈 + 出面试题 → 进项目 → 下一课
```

## 验收铁律

- 每个模块必须：能跑 + 有测试 + 你能讲清"为什么这么设计"
- 宁可砍功能，不砍理解。**讲不清的代码 = 没写。**
- 每天一个 Git 提交：面试时要能展示真实的开发历史
