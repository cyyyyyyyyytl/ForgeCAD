# 矩形、圆形草图与拉伸

## 拉伸切除接菜单

在“建模”菜单添加“拉伸切除”，objectName 设置为 `actionExtrudeCut`。
槽 `on_actionExtrudeCut_triggered()` 和对话框已实现，无需另外创建对话框 .ui。
主体列表只包含当前可见的有效实体，草图列表包含矩形和圆形草图。

验证：新建 20×20×10 的长方体；创建半径 2、圆心 X=10、Y=10 的圆形草图。
拉伸切除选择长方体和圆形草图，正向切除 10 mm，得到贯穿孔；5 mm 得到从 Z=0 一侧进入的盲孔。
草图平行于世界 XY 平面，切除起点取草图 Z 高度；属性面板支持点击定位。
不支持任意面朝向的草图或“贯穿全部”终止条件，详见 [点击定位](click-placement.md)。

切除参数为正高度和方向，依赖顺序为主体、草图。重建时复用拉伸生成工具体，再做差集。
它是一个 ExtrudeCut 特征，工具体不单独出现在模型树中；创建、撤销、重做均为一步操作。
修改主体、草图或切除参数会重算；删除主体或草图会级联删除切除，撤销可恢复。
新建时没有体积交集会拒绝创建并提示；后续参数编辑失去交集会标记失败并显示上游输入。
完全切空是合法空结果。保存打开保留切除参数和依赖，连续开孔可以选择上次切除的结果作为主体。

## 接菜单

已有矩形草图 QAction：`actionNewRectangleSketch`。
在“新建”菜单添加“圆形草图”，objectName 设置为 `actionNewCircleSketch`。
圆形草图创建槽已实现，对话框输入半径和圆心 X/Y/Z，保持平行于 XY 平面。
在“新建”或“建模”菜单增加文字“拉伸”，objectName 必须是 `actionExtrude`。
MainWindow 的槽与拉伸对话框已实现，Qt 按名称自动连接；不需要另建对话框 .ui。
保存 Designer 文件并重新构建，退出旧程序后启动新版。

## 试一次完整流程

1. 创建矩形草图：长 10、宽 20、X=-3、Y=4。
2. 点击拉伸：选择该草图，高度 5 mm，确定。
3. 视口显示实体，模型树仍保留草图；修改草图长宽会重算实体。
4. 选中拉伸，属性区可以修改高度和方向。高度范围 1–10000 mm，方向支持正向、反向和对称。
5. 撤销创建拉伸会恢复草图显示；重做恢复实体。
6. 删除草图会提示级联删除拉伸；一次撤销恢复整组对象。

## 代码只看这条链

```text
actionExtrude
  → MainWindow::on_actionExtrude_triggered()
  → ModelDocument::createExtrudeFeature(草图 ID, 高度)
  → 依赖图记录 Extrude001 → RectangleSketch001
  → rebuildReport() 先算草图，再把轮廓传给拉伸
  → ExtrudeFeature::rebuild(inputs)
  → ShapeFactory::extrudeWire(轮廓, 高度)
  → MakeFace 填面 → MakePrism 沿所选 Z 方向生成实体
```

草图保存尺寸和位置；拉伸保存高度与方向，输入 ID 由依赖图保存。
不在两个对象里重复保存长宽，这样修改草图时才能自动更新下游。
创建对象与登记依赖在一次文档操作中完成，Undo 不会留下没有输入的拉伸。
成功拉伸隐藏其输入草图；计算失败时展示可用的上游，便于修正模型。

原生保存/打开已识别两个新类型；STEP 导出使用最终拉伸实体，不额外导出其隐藏草图。
这次只补新类型兼容，不扩展文件工作流。

当前支持平行于 XY 平面的参数矩形、圆形和独立拉伸实体，不含鼠标画线、约束求解、
旋转草图平面、带孔多轮廓或自动合并已有实体。

## 圆形草图验证

创建半径 10、圆心 X=-3、Y=4 的圆形草图，再拉伸 5 mm。
拉伸对话框同时列出矩形和圆形草图，并优先选择当前选中的草图。
修改圆形草图半径后，圆柱自动更新；撤销、重做、级联删除和原生保存打开保留依赖。

## 拉伸方向

创建窗口和拉伸属性面板提供“正向（+Z）”“反向（-Z）”“对称（两侧各一半）”。
高度始终为正，表示总厚度：草图 Z=0 时，20 mm 的正向范围为 Z=0..20，反向为 -20..0，对称为 -10..10。
草图位于其他高度时，范围随草图一起平移。对称模式先把输入轮廓沿 Z 平移 -height/2，再沿 +Z 拉伸 height。
方向随参数一起进入撤销历史和原生文件；旧文件缺少 direction 时默认正向。
现有 actionExtrude 和对话框代码继续使用，无需新增 QAction 或 Designer 控件。
