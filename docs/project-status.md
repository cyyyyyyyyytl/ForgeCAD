## 已验证的闭环

- 参数编辑→上游／下游重建→失败反馈→撤销重做。
- 原生保存读取和STEP往返，不依赖导出模型恢复参数历史。
- Designer新增8个QAction真实触发、菜单归属、对话框、创建、编辑、取消。
- 曲线空心杯身、放样立柱、圆台底座、两侧扫掠杯耳组成单实体；检查杯腔仍为空。

三个Release目标为forgecad、forgecad_tests、forgecad_ui_tests。最近206／206 CTest通过；测试使用离线工具JSON和offscreen界面，不调用DeepSeek。几何正确不能证明成品美观，界面测试也不能替代真实三维渲染验收。最新菜单验证日志为`build-feedback/designer-actions-tests.log`，日志和构建产物不进入Git。
