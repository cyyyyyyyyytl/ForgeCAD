# 点击定位与草图高度

## 使用

新建圆形或矩形草图后，选中模型树中的草图，在属性面板点击“点击定位…”。
移到视口，黄色标记表示候选位置，状态栏显示 XYZ。左键单击确认，Esc 取消。
圆形草图定位圆心，矩形草图定位左下角；基础体也支持定位其角点、底面圆心或球心。
当前被定位的显示对象不参与目标拾取，避免总是命中自己。
主体支持精确曲面求交；未命中实体时投影到当前对象 Z 高度的 XY 工作平面。
相机射线平行于工作平面时没有有效投影，需要旋转视角后再点击。

按钮由代码生成，不必修改 Designer。也可在“建模”菜单添加“点击定位”，
objectName 为 `actionPlaceFeature`，同名槽已提供。

## 顶面盲孔

1. 创建 20×20×10 的长方体，位置默认。
2. 创建圆形草图，只输入半径 2，其他参数默认。
3. 点击定位，在长方体顶面中间单击，圆心 Z 应为 10。
4. 拉伸切除，选择主体和圆形草图，反向切除 5 mm。
5. 撤销一次切除，再撤销一次定位，草图 XYZ 一起恢复。

## 实现

Viewport3D 根据相机生成视线射线，PointPicker 使用
IntCurvesFace_ShapeIntersector 求最近的正向曲面交点；空白位置做射线与水平工作平面的求交。
鼠标移动只预览候选点，确认后由 MainWindow 调用 ModelDocument::setPosition。
文档一次写入 XYZ，记录一次历史，随后重建所有下游。
矩形和圆形草图新增 Z 参数，保持平行于 XY 平面；原生文件保留 Z，旧草图缺少 Z 时补零。

当前是世界坐标定位，不会根据面法向旋转草图，也不会在主体改变后自动跟随该面。
尚未提供顶点/边中点/圆心捕捉、网格吸附和坐标轴拖动手柄。
后续可在已有拾取和原子定位接口上增加这些交互。
