C++ 秋招一个月：高强度技术栈 + 完整项目规划
================================================

目标
----
目标不是做一个“能跑的 Demo”，而是用一个月做出一个具备真实工程复杂度、可以写进 C++/工业软件/3D/CAD/客户端岗位简历，并且能够支撑面试深挖的完整项目。

项目定位
--------
项目名称：ForgeCAD —— C++ 参数化三维建模与几何分析平台

定位：
- 面向 C++ 工业软件 / CAD / 3D / 几何算法岗位
- 自研应用层架构 + OpenCASCADE 几何内核
- Qt 桌面 GUI
- CMake 工程化
- Linux/Windows 双平台构建能力
- 多线程、任务系统、日志、异常、单元测试、性能测试
- 参数化建模 + 特征树 + Undo/Redo + STEP 数据交换
- 不追求“功能很多”，而追求架构、抽象、算法、工程质量和可扩展性
- 最终效果应该像一个“小型专业 CAD 内核应用”，而不是学生作业

项目核心功能
============

1. 参数化建模系统
----------------
支持：
- Box
- Cylinder
- Sphere
- Cone
- Torus
- Extrude
- Revolve

每个模型具有参数对象，例如：
Box:
  length
  width
  height

Cylinder:
  radius
  height

要求：
- 修改参数后重新生成 Shape
- Feature 有唯一 ID
- Feature 有名称
- Feature 有参数
- Feature 有输入依赖
- Feature 有输出 Shape

重点学习：
- OOP
- polymorphism
- Factory
- Domain Model
- 参数化建模思想


2. Feature Tree / 参数历史树
----------------------------
类似 CAD 软件：
Body
  ├── Sketch
  ├── Extrude
  ├── Fillet
  ├── Cut
  └── Chamfer

要求：
- Feature 树
- 父子依赖
- 参数修改后增量重建
- 重建失败状态
- Feature suppress / unsuppress
- Feature reorder 基础

重点：
- DAG
- Dependency Graph
- Topological Sort
- Command
- 状态管理
- CAD 参数化思想


3. Boolean Kernel
-----------------
实现：
- Fuse
- Cut
- Common

要求：
- 两个或多个 Shape
- 错误检测
- 运算耗时统计
- 无效 Shape 检查
- 失败后返回可解释错误

重点：
- OCCT
- B-Rep
- 几何有效性
- 异常处理
- 性能


4. 几何分析模块
----------------
支持：
- Volume
- Surface Area
- Center of Mass
- Bounding Box
- Vertex count
- Edge count
- Face count
- Solid count

进一步：
- 两个实体距离
- 点到面距离
- 面积排序
- 最大/最小尺寸
- 模型尺寸统计

要求统一接口：
IShapeAnalyzer

重点：
- Interface
- Strategy
- Visitor
- 几何遍历


5. 交互式 3D View
-----------------
实现：
- 旋转
- 平移
- 缩放
- Fit All
- 正交/透视切换
- 选择实体
- Face/Edge/Vertex 高亮
- 模型树与 3D 视图联动
- 基本坐标轴/Gizmo

重点：
- Qt
- OpenGL/3D rendering
- Camera
- Coordinate Transform
- Picking


6. Sketch / 草图模块（简化但要有水平）
--------------------------------------
不要做完整商业 CAD Sketcher，而是实现一个可扩展的二维草图系统。

支持：
- Point
- Line
- Circle
- Arc
- Rectangle

约束：
- Horizontal
- Vertical
- Coincident
- Parallel
- Perpendicular
- Distance
- Radius

目标：
- 草图几何对象 + 约束对象分离
- 参数化约束
- 基础约束求解
- 草图可用于 Extrude

如果一个月时间不足：
优先实现几何对象 + 少量约束 + 参数驱动，不要追求完整求解器。


7. Undo / Redo
--------------
所有重要操作走 Command：

CreateFeatureCommand
DeleteFeatureCommand
ModifyParameterCommand
BooleanCommand
TransformCommand

要求：
- Ctrl+Z
- Ctrl+Y
- Command Stack
- 支持连续操作
- 参数修改可撤销

重点：
- Command Pattern
- 状态管理
- 对象生命周期


8. STEP 文件系统
----------------
实现：
- STEP Import
- STEP Export
- 文件错误处理
- 最近打开文件
- 模型元数据

进一步：
- 大模型加载异步化
- 加载进度
- 加载耗时统计

重点：
- IO
- OCCT Data Exchange
- Threading
- Error Handling


9. 异步任务系统
----------------
自己实现轻量 Task System：

Task
TaskQueue
ThreadPool
Future/Promise

应用：
- STEP 加载
- Boolean
- Shape Analysis
- 大模型计算

要求：
- GUI 不阻塞
- 任务取消基础能力
- 任务状态
- 进度回调
- 错误回调

重点：
- std::thread
- mutex
- condition_variable
- atomic
- future
- Producer/Consumer
- Thread Pool


10. 日志与错误系统
------------------
使用：
- spdlog

日志级别：
TRACE
DEBUG
INFO
WARN
ERROR

记录：
- Feature 创建
- Boolean
- STEP IO
- Task
- 异常
- 性能

错误模型：
- expected 风格返回值或统一 Result
- Exception 用于真正异常情况
- GUI 层显示用户可理解错误


11. 性能分析
------------
建立 Benchmark 模块。

统计：
- Shape 创建耗时
- Boolean 耗时
- STEP Import 耗时
- STEP Export 耗时
- Shape Analysis 耗时

输出：
- 单次耗时
- 平均耗时
- P95/P99（如果时间允许）

进一步：
- 不同模型数量
- 不同模型复杂度
- 多线程前后对比

重点：
- 性能意识
- profiling
- 时间复杂度
- 内存管理


12. 测试系统
------------
GoogleTest。

至少测试：
- 参数校验
- Box 创建
- Cylinder 创建
- Boolean
- Volume
- Bounding Box
- Transform
- Feature dependency
- Undo/Redo
- STEP Import/Export

增加：
- Regression Test
- 异常输入测试


13. AI 建模助手（最后加入）
--------------------------
最终可以增加：

用户输入：
“创建一个长 100、宽 50、高 30 的盒子，然后在中心打一个直径 20 的通孔。”

AI 不直接生成 C++ 代码。

AI 输出结构化命令：
{
  "operations": [
    {
      "type": "create_box",
      "length": 100,
      "width": 50,
      "height": 30
    },
    {
      "type": "create_cylinder",
      "radius": 10,
      "height": 30
    },
    {
      "type": "boolean_cut",
      "target": "Box001",
      "tool": "Cylinder001"
    }
  ]
}

C++ Application Layer 验证参数后执行。

重点：
- LLM API
- Structured Output
- Tool Calling
- Schema Validation
- AI 与核心业务解耦

这会形成：
自然语言 -> AI -> 建模指令 -> C++ -> OCCT -> 3D 模型
